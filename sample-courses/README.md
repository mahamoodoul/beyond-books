# Sample courses (OpenStax textbooks)

Four free, openly licensed textbooks from [OpenStax](https://openstax.org) (Rice University), used as
sample sources for Beyond Books courses. The course excerpts (the PDFs the courses are built from)
are in the repo via **Git LFS** (`git lfs install && git lfs pull`). The full books are not
(55-208 MB each, two are over GitHub's 100 MB limit): download them from the links below.

| Course | Full book (source) | Excerpt to upload (≤ 50 MB) | Licence |
|---|---|---|---|
| Biology | [Concepts of Biology](https://openstax.org/details/books/concepts-biology) | Ch. 3–4 *Cell Structure and Function*, *How Cells Obtain Energy* | CC BY-NC-SA 4.0 |
| Chemistry | [Chemistry 2e](https://openstax.org/details/books/chemistry-2e) | Ch. 2 *Atoms, Molecules, and Ions* | CC BY-NC-SA 4.0 |
| Mathematics | [Algebra 1](https://openstax.org/details/books/algebra-1) | Unit 1, Lessons 1.1–1.6 *Expressions and Equations* | CC BY-NC-SA 4.0 |
| Physics | [Physics](https://openstax.org/details/books/physics) | Ch. 2–4 *Motion in One Dimension*, *Acceleration*, *Forces and Newton's Laws* | CC BY 4.0 |

Each excerpt keeps the book's title and licence pages at the front.

**Attribution:** Content © OpenStax, Rice University, licensed under the Creative Commons licence
shown above. Excerpts were made by extracting pages; no text was changed. CC BY-NC-SA material may
only be used non-commercially and adaptations must use the same licence.

**Why excerpts:** the app accepts PDFs up to 50 MB, and the AI course outline reads about the first
120,000 characters of the sources, so a course works best from a few chapters at a time.
